    VPS 线路
    CN2 GIA (AS4809)

    中国电信最高等级精品国际专线，双向全程 59.43 节点，晚高峰极少拥堵。

    VPS 线路
    CUII / AS9929

    中国联通精品 A 网国际线路，对标电信 CN2 GIA，延迟低且晚高峰稳定。

    VPS 线路
    CMIN2 (AS58807)

    中国移动新一代精品国际专线，大幅改善移动跨境晚高峰丢包。

    VPS 线路
    4837 / 软银 / CMI / IIJ

    高性价比次优直连回程：联通 AS4837、日本 SoftBank/IIJ、移动 CMI 与亚太 Lumen，适合日常大流量。

    VPS 落地
    真家宽 vs 双 ISP 伪家宽

    真家宽接入当地本土运营商（如 Hinet、AT&T、HKT）；双 ISP 伪家宽物理托管在机房但宣告了住宅属性 IP 段。

    VPS 落地
    NAT 家宽 / 共享端口机

    多人共享公网家宽 IP、按分配端口范围入站，以百元内年付体验真实住宅出口，需关注邻居风控与协议限制。

    VPS 测评
    NodeQuality (NQ) / TQuality

    社区主流综合体检脚本：NQ 聚合 GB5/磁盘 fio/IP 质量/流媒体解锁/三网回程；TQ 侧重三网 TCP 大包重传与单线程实测。

    VPS 组网
    链式代理 / IX / Po0

    通过线路机前置拉取家宽/机房落地机出口（如 Mihomo dialer-proxy 或服务端转发），兼顾国内低延迟接入与纯净海外身份。

    FSAE 赛车
    BMS / IMD / BSPD

    电池管理系统（BMS）、绝缘监测装置（IMD）与制动系统合理性检测器（BSPD），电车安全回路三大核心。

    FSAE 赛车
    TSAL (高压指示灯)

    Tractive System Active Light，用于指示整车动力系统是否带高压电的车外频闪安全灯。

    RoboMaster
    C板 / CAN 总线 / 达妙

    STM32F407 开发板（C型）通过 1Mbps CAN 总线驱动大疆 M3508/GM6020 或达妙关节电机。

    AI 工程
    RAG / vLLM / KV Cache

    检索增强生成（RAG）结合外部知识库降低幻觉；vLLM 利用 PagedAttention 管理 KV Cache 显著提升推理吞吐。
