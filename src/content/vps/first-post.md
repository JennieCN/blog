这是「融夕的书」的第一篇文章，记录整个站点的架构选型与落地过程。

## 整体架构设计

站点采用前后端分离的双层结构：

- **内容主站（`blog.mycampusmail.com`）**：基于 Astro 5 构建纯静态页面，托管在 Cloudflare Pages，集成 Pagefind 离线全文搜索与 Waline 评论。
- **问答社区（`qa.mycampusmail.com`）**：基于 AWS 新加坡实例运行 Flarum 论坛，支持访客自助注册、按五个板块发帖提问、上传图片与采纳最佳解答。

### 为什么把博客与社区拆开

静态站点的优势是首屏极快、零维护、不怕流量突发；而注册制问答需要持久化的用户状态与实时通知。把两者通过顶部导航栏与文章底部板块链接打通，既保住了静态站的速度，又拥有完整的社区互动。

## 常用服务器巡检命令

日常排查 VPS 资源与网络状态时最常用的命令如下（可点击右上角一键复制）：

```bash
# 查看 CPU、内存、Swap 与磁盘占用
nproc && free -m && df -h /

# 查看监听中的 TCP/UDP 端口
ss -lntup
```
